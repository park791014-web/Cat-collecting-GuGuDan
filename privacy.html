구구단 대모험 개인정보처리방침

구구단 대모험 운영자는 학습 게임 제공에 필요한 최소한의 정보만 처리하고, 이용자의 개인정보를 안전하게 보호하기 위해 다음과 같이 개인정보처리방침을 공개합니다.

시행일: 2026년 8월 12일

제1조(적용 대상과 운영 원칙)

이 방침은 구구단 대모험 웹 앱의 회원 계정과 게임 이용에 적용됩니다. 게스트 이용은 계정을 만들지 않으며 게임 데이터가 현재 브라우저의 세션 저장소에만 저장됩니다.

제2조(처리하는 개인정보 항목)

구분처리 항목수집 방법
계정 생성·로그인로그인 ID, Firebase UID, 비밀번호 인증정보회원가입 및 로그인 화면. 비밀번호는 Firebase Authentication이 인증하며 앱의 Firestore 데이터베이스에는 평문 비밀번호를 저장하지 않습니다. 로그인 ID는 인증용 내부 이메일 생성에 SHA-256 방식으로 변환되지만 프로필 표시와 계정 관리를 위해 원래 로그인 ID도 처리합니다.
프로필·랭킹닉네임, 대표 고양이, 점수, 랭킹 종류, 플레이·갱신 시각프로필 설정과 게임 결과 저장
게임 진행레벨, 누적 점수와 정답 수, 게임 횟수, 모험 진행·별·보상, 보유 고양이와 재화, 미션·시즌 진행, 앱 데이터 버전게임 이용 중 자동 생성·저장
로컬 설정사운드·진동·화면 설정, 온보딩 상태, 게임 데이터 사본브라우저 localStorage 또는 sessionStorage
접속 정보IP 주소, 브라우저·기기 정보, 접속 시각, 오류·보안 로그가 서비스 제공자의 로그에 포함될 수 있음Vercel 및 Google Firebase가 호스팅·보안 운영 과정에서 자동 처리

이 앱은 실명, 학교명, 학년·반, 주소, 전화번호, 위치정보, 사진, 음성, 결제정보를 입력받지 않으며 외부 AI API를 사용하지 않습니다.

제3조(처리 목적)

  • 회원 식별, 로그인 및 계정 유지
  • 구구단·나눗셈 학습 게임, 모험 진행, 보상과 고양이 수집 기능 제공
  • 본인 기록 저장, 닉네임 기반 랭킹 표시
  • 오류 대응, 부정 이용 방지, 서비스 보안과 안정성 유지

제4조(보유 기간과 파기)

  • 회원 계정·Firestore 게임 데이터: 회원 탈퇴 또는 삭제 요청 처리 시까지 보관한 뒤 삭제합니다. 법령에 별도 보존 의무가 있는 경우에만 해당 기간 동안 분리 보관합니다.
  • 브라우저 localStorage: 이용자가 설정의 데이터 초기화를 실행하거나 브라우저 저장 데이터를 삭제할 때까지 보관됩니다.
  • 게스트 sessionStorage: 해당 브라우저 탭 또는 세션이 끝날 때 삭제됩니다.
  • 서비스 로그: Vercel·Google Firebase의 보안 및 운영 정책에 따른 기간 동안 처리될 수 있습니다.

전자적 파일은 복구하기 어려운 방법으로 삭제하며, 종이 문서는 수집하지 않습니다.

제5조(제3자 제공과 공개 범위)

운영자는 개인정보를 판매하거나 별도의 제3자에게 제공하지 않습니다. 다만 법령에 근거한 적법한 요청이 있는 경우는 예외입니다.

랭킹 화면에는 이용자가 정한 닉네임, 점수, 대표 고양이, 기록 시각이 다른 이용자에게 표시될 수 있습니다. 로그인 ID와 비밀번호는 랭킹에 공개하지 않습니다.

제6조(처리 위탁과 국외 처리 가능성)

수탁자위탁 업무처리 항목과 방식
Google LLC (Firebase Authentication, Cloud Firestore)회원 인증, 계정 및 게임 데이터 저장·조회, 보안 로그제2조의 계정·프로필·게임 데이터가 가입·로그인·저장 시 TLS로 전송됩니다. Google이 운영하는 미국 등 국외 데이터센터에서 처리될 수 있으며, 계약 종료 또는 데이터 삭제 시까지 처리됩니다.
Vercel Inc.정적 웹 앱 호스팅, 전송, 접속·보안 로그앱 파일 요청 과정의 IP 주소, 브라우저·기기 정보, 접속 시각이 TLS로 전송되어 미국 등 Vercel이 운영하는 국외 인프라에서 처리될 수 있습니다.

이 앱은 OpenAI 등 외부 AI 서비스에 학생 정보나 답안을 전송하지 않습니다.

제7조(정보주체의 권리와 행사 방법)

이용자 또는 법정대리인은 자신의 개인정보 열람, 정정, 삭제, 처리정지를 요청할 수 있습니다. 앱을 안내한 담당 교사에게 직접 요청하면 본인 또는 법정대리인 여부를 확인한 뒤 관련 법령에서 정한 기간 안에 처리합니다.

설정의 “전체 게임 데이터 초기화”는 현재 기기의 로컬 데이터만 삭제합니다. Firebase 계정·게임 데이터·랭킹까지 삭제하려면 담당 교사에게 별도로 요청해야 합니다.

제8조(만 14세 미만 아동의 개인정보 보호)

만 14세 미만 이용자는 법정대리인의 동의를 받은 뒤 담당 교사의 안내에 따라 가입해야 합니다. 가입 화면에서 해당 동의 여부를 확인하며, 동의 여부를 확인할 수 없으면 회원가입을 진행하지 않습니다. 법정대리인은 제7조의 권리를 행사할 수 있습니다.

제9조(안전성 확보 조치)

  • HTTPS/TLS를 통한 전송 암호화와 HTTP의 HTTPS 전환
  • Firebase Authentication을 통한 비밀번호 인증
  • Firebase UID 기준 Firestore 접근 통제 및 관리자 권한 분리
  • CSP, 클릭재킹 방지, MIME 추측 방지, Referrer·Permissions 정책 적용
  • 게스트 데이터를 서버가 아닌 현재 브라우저 세션에만 저장

제10조(개인정보 보호책임자와 문의)

개인정보 보호책임자: 구구단 대모험 운영 담당 교사
권리 행사·개인정보 문의: 앱을 안내한 담당 교사에게 직접 문의

일반 기능 문의는 공개 문의 게시판을 이용할 수 있습니다. 공개 게시판에는 로그인 ID, 비밀번호, 실명 등 개인정보를 작성하지 마세요.

개인정보 침해 상담은 개인정보침해 신고센터(국번 없이 118) 또는 개인정보 분쟁조정위원회에서 도움을 받을 수 있습니다.

제11조(방침 변경)

처리 항목이나 서비스가 변경되면 이 페이지를 통해 시행 전에 알립니다.
